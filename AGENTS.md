# Работа с проектом DSM

Использовать навык в `skills/edit-dsm-project/SKILL.md`. Старт из корня репозитория: `node dsm.cjs --help`. Рабочий документ задаёт пользователь. Примеры в `example/` предназначены для копирования.

Из произвольного входа составить проверяемую таблицу-кандидат. Отметить неполные строки, сохранить исходные ID, единицы оценки и основания связей. Прочитать project и base, выполнить preview, затем apply для порученного изменения. При совпадении базы использовать одну атомарную транзакцию. По завершении сообщить текущую версию и экспортировать нужное представление.
