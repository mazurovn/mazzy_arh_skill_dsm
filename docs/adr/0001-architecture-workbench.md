# ADR-0001. Общая ревизия архитектурных артефактов

Статус — принято. Предложение OpenSpec — `architecture-workbench`. Спецификации — `architecture-views` и `notebook-session`.

## Контекст

Редактор и агент одновременно работают с матрицей. Экспортированная таблица или исполняемый блокнот могут оставаться открытыми после изменения проекта другим автором.

## Решение

Хранить предложение OpenSpec, решение ADR и сценарий как объекты с постоянными ID. Поле refs задаёт проверяемые ссылки на объекты, steps задаёт упорядоченные вызовы. Граф, реестр и DSM читают одну версию. Решение ссылается на предложение и затронутые элементы. Внешний Markdown хранится в описании документа. Для работы с Git автор выгружает его под соответствующим именем.

Блокнот получает собственный файл и исходную ревизию. Его сохраняет Jupyter. Перенос изменений в матрицу требует предпросмотра и совпадения базы под файловой блокировкой.

## Последствия

У сценария можно повторить вызов. Удаление используемого контракта требует одновременно поправить сценарий. Старые табличные проекции читаются с пустыми дополнительными полями. Sysl передаёт структуру вызовов, а полная история хранится в JSON или HTML.
