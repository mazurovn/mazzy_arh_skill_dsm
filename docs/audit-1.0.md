## Подключение агентов

Проверен общий сервер stdio на Dell. Claude Code и Qwen Code показали Connected. Grok прошёл handshake и обнаружил семь инструментов. Codex App Server вернул семь инструментов при запросе статуса MCP. Kimi Code 2.4.1 запросил список семи инструментов в изолированной сессии с локальным синтетическим ответчиком. Независимый Python SDK MCP вызвал все семь инструментов, включая запись, отказ при устаревшей базе и восстановление. Это измеряет совместимость транспорта и операций. Качество архитектурных выводов внешних моделей требует отдельной предметной оценки.

## Границы выпуска

- В файле HTML работают автономная матрица, анализ, схемы, артефакты и обмен. Для исполнения Python нужен локальный сервер и окружение Jupyter.
- Sysl экспортирует статические вызовы. Авторский порядок поведения хранится в сценарии, документ и история — в JSON или HTML.
- Отклонение регистрирует автор. Поля expected и actual можно использовать для любых единиц. Список открытых отклонений строится по ссылкам и состоянию карточек.
- Участники локальных процессов работают с одним физическим JSON. Проект использует полные снимки и файловую блокировку. Многопользовательское сетевое развёртывание, роли и аудит доступа потребуют отдельного проектирования.
- Методическая сверка с приложением к ДЗ № 3 приведена со слов автора. Файл приложения не входил в материалы этой проверки.
