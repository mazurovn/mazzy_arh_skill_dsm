## Context

Начальная точка — f0b3e92. Десять исходных тестов ядра прошли. Покрытие загруженных ими модулей составило 89,17% строк и 78,39% ветвей. Модуль запуска Jupyter получил 30,16% строк. Исполнение ячеек проверяется отдельным тестом с браузером.

## Decisions

Чтение nbformat и операции с документом вынести из контроллера. Сохранённые блокноты открывать копией в отдельной сессии. Просмотр текста и результатов доступен в автономном HTML. Нативное выполнение требует явного запуска с локального origin.

Запрос, задача и предложение имеют собственные ID в модели. Конвертация запроса и применение предложения атомарны. ZIP содержит базу и индекс редактируемых документов. Изменения применяются через обычный предпросмотр. Отчёты возвращают таблицы с ID для редактора, CLI и CSV.

## Risks / Trade-offs

Документ ipynb может содержать чужой код и богатые выводы. Предпросмотр отображает их текстовое представление. Существующие рабочие файлы остаются под управлением Jupyter. История измеряет состояние архитектурной модели, а не изменения Python-кода между сохранениями.
