## ADDED Requirements

### Requirement: Путь разработки изделия
DSM SHALL показывать состав станка, интерфейсы, связанное требование и результат проверки клиентской программы по одной модели.

#### Scenario: Задание технолога
- **WHEN** пользователь испытывает программу в поддержанном линейном подмножестве
- **THEN** редактор показывает траекторию и первую ошибочную строку при выходе за пределы рабочего объёма

### Requirement: Расчёт по версии
DSM SHALL независимо рассчитывать объём диагностической записи и пригодные компоненты в браузере и Jupyter.

#### Scenario: Требование изменено во время расчёта
- **WHEN** расчёт с прежней базой возвращается после изменения длительности записи
- **THEN** редактор отклоняет запись, а новый расчёт учитывает изменённое требование и ссылается на его ID

### Requirement: Связность представлений изделия
DSM SHALL строить MDM функции и реализации, две DSM, порядок кластеров и реестр контрактов из текущих карточек изделия.

#### Scenario: Проверка контракта клиента и прошивки
- **WHEN** технолог открывает вес пары в слое совместных проверок
- **THEN** общий инспектор показывает основание той же связи, а программная архитектура и реестр сохраняют ID участников

### Requirement: Приём диагностического файла
DSM SHALL проверять двоичный формат VIB1 и сохранять идентификатор файла и исходную ревизию в протоколе.

#### Scenario: Неполная и повреждённая запись
- **WHEN** клиент читает запись с недостающим последним блоком либо изменённым байтом полезных данных
- **THEN** первый файл получает результат неполного окна, а во втором случае проверка сообщает ошибку CRC

#### Scenario: Совместимость с регистратором
- **WHEN** переносимый регистратор C99 кодирует два модельных потока, а клиент открывает его файл
- **THEN** число отсчётов и размер в байтах совпадают с расчётом Jupyter для той же длительности

#### Scenario: Анализ исходной записи в Jupyter
- **WHEN** технолог открывает проверенный файл в блокноте
- **THEN** блокнот переносит байты, проверяет SHA-256, разбирает блоки в Python и строит график отсчётов
